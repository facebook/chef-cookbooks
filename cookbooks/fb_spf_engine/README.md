fb_spf_engine Cookbook
======================

Requirements
------------
On RHEL/CentOS, this requires EPEL be configured.

Attributes
----------
* node['fb_spf_engine']['config']
* node['fb_spf_engine']['manage_packages']

Usage
-----
This cookbook sets `spf_engine` up as a Milter. While it can be setup in other
ways, as a milter is the preferred mechanism from upstream.

### Packages

This cookbook will install the necessary packages. If you prefer to install
them yourself, set `node['fb_spf_engine']['manage_packages']` to `false`.

### Configuration

The configuration file is generated by the single-level hash in
`node['fb_spf_engine']['config']`. A default configuration is provided in this
cookbook.

Values can an array and the values will automatically be joined by a comma.

**NOTE**: `spf_engine`/`pyspf` is incredibly picky about the casing of its
configuration keys. Worse, it's quite inconsistent (e.g. `debugLevel` vs
`TestOnly` keys). Moreover, values are inconsistent as well - for most booleans
anything other than exactly `True` is treated as false.

While it is a common pattern in FB-style cookbooks to downcase all keys to
eliminate possible conflicts, that is not possible in this case, so ensure
you're careful.

### Using with `fb_postfix`

To use this with `fb_postfix`, there are a few necessary steps:

Create a directory in postfix's chroot for the socket and set the milter
to put its socket there:

```ruby
rundir = '/var/spool/postfix/spf_engine'
directory rundir do
  owner 'pyspf-milter'
  group 'postfix'
  mode '0750'
end

node.default['fb_spf_engine']['config']['Socket'] =
  "local:#{rundir}/pyspf-milter.sock"
```

Make sure the `postfix` user is in the `pyspf-milter` group:

```ruby
group 'pyspf-milter' do
  members 'postfix'
end
```

Or, if you use `fb_users`, then:

```ruby
node.default['fb_users']['groups']['pyspf-milter']['members'] << 'postfix'
```

Finally, add the milter to postfix's `smtpd_milters`:

```ruby
node.default['fb_postfix']['main.cf']['smtpd_milters'] =
  'local:spf_engine/pyspf-milter.sock'
```

If you're using `fb_opendkim` as well, make sure opendkim's milter is first:

```ruby
node.default['fb_postfix']['main.cf']['smtpd_milters'] = [
  'local:opendkim/opendkim.sock',
  'local:spf_engine/pyspf-milter.sock',
].join(',')
```
